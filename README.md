An entry for the [make.fun bounty "The Meeting That Should Have Been One Line"](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c): one sentence that could have replaced an entire pointless meeting. No context, no explanation — just the line that kills the meeting.

## The line

> We spent an hour agreeing on nothing, then scheduled another meeting to decide what we agreed on.

## How it works

`main.ts` writes that single sentence to `/output/entry.txt` (one line, 97 characters — inside the gate of 1–200 characters) and self-checks the gate before exiting.

Run it with Node 22.18 or later:

```sh
node main.ts
```
